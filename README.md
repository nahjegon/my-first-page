# 플레이리스트 추출기

내 구글 계정의 YouTube 플레이리스트를 화면에서 보고 **엑셀(.xlsx)**이나 **CSV**로 저장하는 로컬 웹 앱입니다.
서버 없이 브라우저에서 YouTube Data API를 직접 호출하므로 데이터가 다른 곳으로 전송되지 않습니다.

## 실행

- 배포된 사이트: https://my-first-page-three-sandy.vercel.app — **구글 계정으로 로그인**만 누르면 됩니다.
- 내 PC에서: `start.bat`을 더블클릭하면 `http://localhost:8000`이 열립니다. (Python이 필요합니다.)

클라이언트 ID는 `index.html`의 `CLIENT_ID` 상수에 들어 있습니다. 다른 Google Cloud 프로젝트를 쓰려면 이 값을 바꾸세요.
비워 두면 화면의 **설정**에서 직접 입력하는 방식으로 돌아갑니다.

> 로그인 없이 화면을 미리 보려면 **"로그인 없이 데모로 보기"**를 누르세요.

## Google Cloud 설정 (처음 한 번, 약 5분)

1. **프로젝트 만들기**
   [console.cloud.google.com](https://console.cloud.google.com)에 접속해 상단 프로젝트 선택 → **새 프로젝트** → 이름(예: `playlist-export`) → 만들기

2. **YouTube Data API 켜기**
   왼쪽 메뉴 **API 및 서비스 → 라이브러리**에서 `YouTube Data API v3` 검색 → **사용**

3. **OAuth 동의 화면 설정**
   **API 및 서비스 → OAuth 동의 화면**(또는 **Google 인증 플랫폼**) → 시작하기
   - 앱 이름: 아무거나 (예: 플레이리스트 추출기)
   - 사용자 지원 이메일: 본인 Gmail
   - 대상: **외부**
   - 연락처 이메일: 본인 Gmail → 완료
   - **대상(Audience) → 테스트 사용자 → 사용자 추가**에서 **본인 Gmail 주소를 꼭 추가**하세요.
     (추가하지 않으면 로그인할 때 "액세스 차단됨" 오류가 납니다.)

4. **클라이언트 ID 만들기**
   **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - **승인된 자바스크립트 원본**: `http://localhost:8000` (끝에 `/` 없이)
   - 리디렉션 URI는 비워 둡니다 → 만들기

5. 생성된 **클라이언트 ID**(`....apps.googleusercontent.com`)를 복사해 앱의 입력란에 붙여넣고 저장합니다.
   클라이언트 ID는 비밀번호가 아니며 이 PC의 브라우저에만 저장됩니다. 클라이언트 **보안 비밀번호(secret)**는 필요 없습니다.

## 사용법

1. **구글 계정으로 로그인** → 계정 선택
   "Google에서 확인하지 않은 앱" 경고가 나오면 본인이 만든 앱이므로 **고급 → (앱 이름)(으)로 이동**을 누르면 됩니다.
2. 왼쪽 목록에서 플레이리스트를 **클릭**하면 영상 목록이 보입니다. 위쪽 검색창으로 제목·채널을 찾을 수 있습니다.
3. 내보낼 플레이리스트를 **체크**한 뒤 **엑셀로 저장** 또는 **CSV로 저장**을 누릅니다.
   - 엑셀: `전체` 시트와 플레이리스트별 시트가 함께 만들어집니다.
   - CSV: 모든 플레이리스트가 한 파일에 담기고 `플레이리스트` 열로 구분됩니다.

저장되는 열: 플레이리스트, 순서, 제목, 채널, 링크, 추가한 날짜, 영상 게시일

## 참고 / 제한

- **나중에 볼 동영상**과 **시청 기록**은 YouTube API가 제공하지 않아 가져올 수 없습니다. (YouTube 정책)
  **좋아요 표시한 동영상**은 가져올 수 있습니다.
- 삭제되었거나 비공개로 바뀐 영상은 `Deleted video` / `Private video`로 표시됩니다.
- 로그인은 1시간 동안 유지됩니다. 만료되면 다시 로그인하세요.
- API 무료 할당량은 하루 10,000 단위이고, 영상 50개당 1단위를 씁니다. 개인 용도로는 충분합니다.
- 주소창이 `http://localhost:8000`이어야 로그인이 됩니다. `index.html`을 직접 열거나 `127.0.0.1`로 접속하면 동작하지 않습니다.
